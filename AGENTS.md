# ui-sdk

Before using ui-sdk, follow the installed `ui-sdk` skill at `.agents/skills/ui-sdk/SKILL.md` when it is available, and read `node_modules/@ui-sdk/react/docs/llms.txt`. To build a new ui-sdk component, search `node_modules/@ui-sdk/react/docs/core.md` by heading and read the neighboring `node_modules/@ui-sdk/react/docs/rendering.md`.
